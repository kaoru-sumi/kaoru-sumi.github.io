# Kaoru Sumi — Academic Website

Official academic website of **Kaoru Sumi**, Professor at the School of Systems Information Science, Future University Hakodate, Japan.

**Website:** https://kaoru-sumi.github.io/  
**日本語:** https://kaoru-sumi.github.io/ja/

## Research

Research areas include affective computing, persuasive and human–AI interaction, embodied and social agents, virtual/mixed/extended reality, serious games, and nonverbal communication.

The website provides research interests, selected publications, recent activities, awards, and information about the **PAHAI (Persuasive and Affective Human–AI Interaction) Laboratory**.

- [Recent Activities](https://kaoru-sumi.github.io/news/)
- [Publications](https://kaoru-sumi.github.io/publications/)
- [Awards](https://kaoru-sumi.github.io/awards/)
- [PAHAI Laboratory](https://kaoru-sumi.github.io/lab/)
- [Contact](https://kaoru-sumi.github.io/contact/)

## Publication status

News about accepted papers is distinguished from formally published bibliographic records. Full publication details are added to the publications data after official publication and verification.

## Website maintenance

This is a bilingual Jekyll website built with the [al-folio](https://github.com/alshedivat/al-folio) academic website theme and hosted using GitHub Pages.

- English homepage: `_pages/about.md`
- Japanese homepage: `_pages/home-ja.md`
- Recent activities: `_news/`
- Publication records: `_bibliography/`
- Site metadata: `_config.yml`

For research details, please refer to the published website rather than template/example content in the repository.
